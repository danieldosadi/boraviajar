# BoraViajar

Planejador de viagem responsivo em português, feito com HTML, CSS e JavaScript.

## Recursos

- Navegação por ícones: Roteiro, Transporte, Acomodação, Passeio, Restaurante e Perfil.
- Linha do tempo por dia e categoria.
- Cadastro e exclusão de planos.
- Personalização do nome da viagem e perfil.
- Persistência no localStorage do navegador.

## Executar

Abra `dist/index.html` no navegador ou sirva a pasta `dist` com um servidor HTTP estático. Não é necessário instalar dependências nem compilar.
