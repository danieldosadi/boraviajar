# BoraViajar

Planejamento de viagem com login por e-mail autorizado e dados no Supabase.

Site: https://danieldosadi.github.io/boraviajar/

Publicação: GitHub Pages, branch main, pasta /docs. A pasta dist contém a cópia anterior de distribuição. Somente a pasta docs é publicada no Pages.

Configure no Supabase a Site URL e os redirects com https://danieldosadi.github.io/boraviajar/. Usuários devem existir em Authentication e ser aprovados na tabela allowed_emails. A chave em config.js é publicável; o banco usa RLS para proteger os dados.
